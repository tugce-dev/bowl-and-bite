# Bowl & Bite 🍲

A responsive restaurant ordering app built with vanilla JavaScript, featuring a complete ordering and checkout experience.

## Live Demo

[View Bowl & Bite Live]

## About the Project

Bowl & Bite is an interactive restaurant ordering application where users can browse menu items, build their order, adjust quantities, complete a mock checkout, and rate their experience.

The project focuses on dynamic DOM manipulation, application state, event handling, and creating an interactive user experience without using a framework.

## Features

- Browse dynamically rendered menu items
- Add meals to an order
- Increase item quantities
- Remove items from the order
- Automatic total price calculation
- Interactive checkout modal
- Form validation using required fields
- Personalized order confirmation
- Interactive 5-star rating system
- Responsive mobile-style interface

## Built With

- JavaScript (ES6)
- ES6 Modules

## How It Works

Menu data is stored separately and imported into the application using ES6 modules. The interface is dynamically rendered based on the current order state.

Users can add menu items and adjust their order before opening the checkout modal. After submitting the payment form, the application displays a personalized confirmation message and allows the user to rate their experience.
